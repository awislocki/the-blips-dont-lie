# The Card File

A mobile-first data blog of numbers pulled live from U.S. government APIs - CFPB, Census, NASA, USGS, Treasury FiscalData, FDIC BankFind, BTS, and city open-data portals. Every cross-dataset claim was recomputed by an independent verification pass before publication; corrections are disclosed in place.

Static site: a single `index.html`, no build step. Open it locally or deploy anywhere static files are served.

Data sources are linked in the page footer.
