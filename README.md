# The Blips Don't Lie

A mobile-first data publication of numbers pulled live from U.S. government APIs - CFPB, Census, NASA, USGS, Treasury FiscalData, FDIC BankFind, IRS SOI, BTS, and city open-data portals. Every cross-dataset claim is recomputed by an independent verification pass before publication; corrections are disclosed in place.

Static site: `index.html`, no build step. The hero globe is real data - every gold point a witnessed meteorite fall, every green point a later find.

Formerly "The Card File".
